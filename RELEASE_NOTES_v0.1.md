# MED9 Checker v0.1

First public release for Windows x64.

- Detect supported MED9 checksum-only and signing layouts.
- Verify and correct flash checksums, with MPC input for supported signing layouts.
- Read and edit supported 2 KiB and 4 KiB EEPROM images.
- Open flash and EEPROM files through the GUI, with the last browse folder saved locally.
- Build a one-file GUI executable with the native C hashing backend.

See the [README](README.md) for build instructions and supported file types.
