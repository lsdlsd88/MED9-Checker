# Privacy policy

MED9 Checker processes the flash and EEPROM files you select on your device.
The application has no telemetry or upload feature. The GUI can display a
VIN, an Immo ID, and file paths from your inputs.

The file picker stores the last selected folder in a settings file under
`%LOCALAPPDATA%\MED9Checker` on Windows. You can delete `last-folder.txt` to
reset the picker. Files you save or export remain at the locations you choose.
